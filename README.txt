INTERVIEW READY WEBSITE - SETUP

1. Copy the two PDFs into assets/documents/ using these exact names:
   Interview-Ready-Student-Handout.pdf
   A1-202610_Interview_Instructions-Rubric.pdf

2. Copy the introductory MP4 into assets/video/ and name it:
   interview-introduction.mp4

3. GitHub Pages:
   - Upload the entire CONTENTS of this folder to the main branch of a new public repository.
   - In repository Settings > Pages, choose "Deploy from a branch", main, /(root), then Save.
   - The seven app buttons use the expected GitHub Pages addresses for the repositories supplied.
   - If an app repository has not enabled GitHub Pages, enable Pages in that repository too.

4. Test:
   - Open index.html locally to inspect the layout.
   - Video playback may be more reliable after the site is published.
   - Click every app and PDF link after publishing.

Files:
   index.html   Page content
   styles.css  Design and responsive layout
   script.js   Glossary search, progress tracking, theme, mobile menu
